# OmniMind – AI Personal Digital Twin

OmniMind is an AI Career Operating System designed to aggregate a user's professional footprint (Resume, GitHub, Projects) and provide AI-driven analysis, career roadmaps, and mock interviews.

## Project Structure

- `frontend/`: React application with Vite, TailwindCSS
- `backend/`: FastAPI application with Python, MongoDB
- `docs/`: Project documentation (Architecture, API, ER Diagrams)
